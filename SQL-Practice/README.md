# SQL Practice Challenges

This folder contains SQL practice challenges and assessments completed as part of my Data Analyst Transition Program.

## Datasets

- **Online Retail:** Business analysis, customer behaviour, product performance, and transaction trends.
- **Ecommerce Sales:** Mixed real-world SQL challenges using an e-commerce sales dataset.

## SQL Files

| File | Description |
|---|---|
| `01_SQL_Interview_Challenges.sql` | SQL interview challenges using the Online Retail dataset |
| `02_SQL_Final_Assessment.sql` | Final SQL assessment covering business analysis problems |
| `03_Mixed_Real_World_SQL_Challenges_Ecommerce_Sales.sql` | Mixed real-world SQL challenges using the Ecommerce Sales dataset |

## Skills Demonstrated

- Filtering, sorting, and aggregation
- GROUP BY and HAVING
- INNER JOINs and subqueries
- Common Table Expressions (CTEs)
- Window functions and ranking
- Date and time analysis
- Customer and product performance analysis
- Business-focused SQL problem solving

## Project Goal

To demonstrate practical SQL skills by solving business problems, analysing sales data, and preparing for Data Analyst roles.

**Tools:** PostgreSQL and GitHub

# Online Retail Data Analysis — SQL & Power BI

## Project Overview
This project analyses an online retail transaction dataset to identify sales trends, customer purchasing behaviour, and product performance.

## Tools Used
- PostgreSQL — SQL queries and data analysis
- Power BI Desktop — interactive dashboards and visualisation
- GitHub — project documentation and portfolio

## Business Questions
- Which products and countries contribute the most transaction value?
- How does transaction value change month by month?
- Who are the highest-value customers?
- How frequently do customers purchase?
- Which customers may need re-engagement?

## Dataset
The project uses the UCI Online Retail dataset, containing invoice numbers, products, quantities, unit prices, invoice dates, customer IDs, and countries.

## SQL Skills Demonstrated
- Aggregations using SUM, AVG, and COUNT
- GROUP BY and HAVING
- Common Table Expressions (CTEs)
- Joins and subqueries
- Window functions
- Date analysis and customer segmentation

## Project Status
- SQL learning and assessment: completed
- SQL portfolio documentation: in progress
- Power BI dashboard: planned

## Data Notes
The dataset contains negative quantities and cancellation-related records. Transaction values are treated as net transaction values and should not automatically be interpreted as completed sales revenue.
